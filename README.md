# ML Visual Interactive

A visual, interactive learning companion to *Visual Guide to Machine Learning*. Explore concepts through diagrams, worked calculations, adjustable examples, workbook case studies, and optional quizzes. Built with React and TypeScript; runs locally without an account or backend.

## Contents

| Chapters | Topics |
| --- | --- |
| 1–6 | Getting started, the ML landscape, data quality, and profiling |
| 7–10 | Classification models, evaluation, and tuning |
| 11–15 | Regression, model diagnostics, and time-series forecasting |
| 16–21 | Unsupervised learning, clustering, association mining, outliers, and dimensionality reduction |
| 97–99 | Supplementary NLP, Computer Vision, and LLM lessons |

## Run locally

```sh
npm ci
npm run dev
```

Open [localhost:5173](http://127.0.0.1:5173). Browse the sidebar or search with **⌘K / Ctrl+K**.

Run `npm run check` for tests, TypeScript checks, and a production build. Source notes and review records live in [docs/](docs/); deferred improvements are in [todo.md](todo.md).
